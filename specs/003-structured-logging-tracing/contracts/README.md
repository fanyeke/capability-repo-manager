# Contracts: Structured Logging & Operation Tracing

## Contract Files

| File | Description |
|------|-------------|
| `log-events.md` | Structured log event schemas for all instrumented flows |
| `operation-events.md` | Operation event DB records and query API |
| `debug-bundle.md` | Debug bundle format and export command |
| `redaction.md` | Sensitive data redaction patterns |

## Scope

These contracts define the observability interfaces for the Capability Repo Manager. They cover:
- Log event formats (machine-readable event names + structured fields)
- Operation event persistence and retrieval
- Debug bundle assembly and structure
- Sensitive data redaction patterns
